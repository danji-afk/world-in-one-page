Wednesday 18 November 2026: the day's world news on one illustrated page. 40 verified stories — three illustrated leads, eight briefing cards each with its own drawing, a dot-matrix world map with numbered pins, forty numbered stories, a day-in-numbers strip and a date check that shows what was deliberately left out as earlier-day news. Claims are attributed; the drawings are original and deterministic (no randomness, no network).

## Run it

```sh
node main.ts
```
